## 📋 Step-by-Step Guide

### **Step 1: Re-submit ang Updated Sitemap** (REQUIRED)

1. **Pumunta sa Google Search Console:**
   - https://search.google.com/search-console

2. **Pumunta sa Sitemaps section:**
   - Sa left sidebar, i-click ang **"Sitemaps"**

3. **I-check ang current sitemap:**
   - Dapat may naka-submit na: `https://aithinkwise.com/sitemap.xml`
   - I-check ang "Last read" date

4. **Re-submit ang sitemap:**
   - Option 1: **I-click ang "RESUBMIT" button** kung meron
   - Option 2: **I-delete muna** ang old sitemap, tapos **i-add ulit**:
     - I-delete ang existing sitemap
     - I-type ang: `https://aithinkwise.com/sitemap.xml`
     - I-click ang "SUBMIT"

5. **Hintayin ang confirmation:**
   - Dapat mag-show na "Success" status
   - Usually 1-2 days bago ma-process ni Google

### **Step 2: Request Indexing para sa Updated Pages** (RECOMMENDED)

Since na-update natin ang sitemap, i-request ulit ang indexing:

1. **Pumunta sa URL Inspection tool:**
   - Sa Google Search Console, gamitin ang search bar sa taas
   - O pumunta sa **"URL Inspection"** section

2. **I-request indexing para sa mga key pages:**

   **Homepage:**
   - I-type: `https://aithinkwise.com/`
   - I-click ang **"Test Live URL"**
   - Tapos i-click ang **"Request Indexing"**

   **Services Page:**
   - I-type: `https://aithinkwise.com/services`
   - I-click ang **"Test Live URL"**
   - Tapos i-click ang **"Request Indexing"**

   **Contact Page:**
   - I-type: `https://aithinkwise.com/contact`
   - I-click ang **"Test Live URL"**
   - Tapos i-click ang **"Request Indexing"**

   **Get Started Page:**
   - I-type: `https://aithinkwise.com/get-started`
   - I-click ang **"Test Live URL"**
   - Tapos i-click ang **"Request Indexing"**

3. **Important Notes:**
   - ✅ Limit: 10 URLs per day (hindi masyado marami)
   - ✅ I-spread ang requests over several days
   - ✅ I-check ang status after 24-48 hours

### **Step 3: Monitor ang Coverage Report** (MONITORING)

1. **Pumunta sa Coverage section:**
   - Sa left sidebar, i-click ang **"Coverage"**

2. **I-check ang status:**
   - **Valid** - Ilan ang properly indexed
   - **Errors** - May errors ba?
   - **Excluded** - Bakit excluded ang iba?

3. **I-check ang "Valid" pages:**
   - Dapat makita mo ang mga pages na indexed
   - I-click para makita ang list

4. **I-check ang "Errors" (kung meron):**
   - I-click ang errors
   - I-review kung ano ang problema
   - I-fix ang issues

### **Step 4: Verify Domain Configuration** (VERIFY)

1. **I-check kung verified ang domain:**
   - Sa top ng page, i-check kung verified ang `aithinkwise.com`
   - Kung hindi, i-verify muna

2. **I-check kung verified ang www version (kung meron):**
   - I-check kung meron din `www.aithinkwise.com` property
   - Kung meron, i-verify din

3. **I-check ang preferred domain:**
   - Sa Settings, i-check kung naka-set ang preferred domain
   - Dapat consistent sa canonical URLs mo
